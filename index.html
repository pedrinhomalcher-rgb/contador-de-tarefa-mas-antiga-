WMS TASK BOT — Tarefa Mais Antiga

Passo a passo para instalar, ativar e utilizar o painel de consulta de tarefas pendentes no WMS.

Ver tutorial ↓Instalar script
Objetivo: facilitar a visualização de tarefas pendentes e a identificação da tarefa mais antiga, conforme os dados retornados pelo WMS. O bot não deve ser tratado como fonte independente quando a consulta não retornar resultados.

Como configurar

Siga as etapas na ordem abaixo

01
PREPARAÇÃO

Instale a extensão Tampermonkey

No navegador Chrome, instale o Tampermonkey pela loja oficial de extensões e confirme a instalação.

02
PERMISSÕES

Habilite scripts do usuário

Confira as permissões do Tampermonkey e, se o Chrome solicitar, ative a opção de permitir scripts do usuário.

03
INSTALAÇÃO

Adicione o script Tarefa Mais Antiga

Quando o arquivo tarefa-mais-antiga.user.js estiver publicado neste repositório, clique no botão Instalar script e confirme a instalação no Tampermonkey. O arquivo funcional deve ser adicionado ao repositório antes desta etapa.

InstalarCancelar
04
ACESSO

Abra a tela correta do WMS

Faça login no Shopee WMS com sua conta autorizada. No menu lateral, acesse Sales Outbound → Sub Picking.

05
ATIVAÇÃO

Abra o painel Tarefa Mais Antiga

Na tela Sub Picking, abra o WMS TASK BOT, defina o período, selecione as zonas e escolha o tipo de tarefa (Todos, Sem Papel ou Merge Line).

06
CONSULTA

Consulte a tarefa mais antiga

Clique em CONSULTAR e acompanhe os resultados. A tabela mostra Task ID, zona, data de criação, tipo e quantidade de peças. Use a data de criação para localizar a tarefa pendente mais antiga.

Quando não houver resultados, confira o período e as zonas selecionadas. Zero tarefas não significa erro na consulta.

Pronto para consultar?

Com o script instalado e o WMS aberto, acesse o painel e verifique suas tarefas pendentes.
